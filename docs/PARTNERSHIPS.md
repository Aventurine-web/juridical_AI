# Partnerships

> Who could distribute, power, or co-sell this agent. Think distribution first.

## Distribution partners (get in front of users)
- Communities / newsletters / influencers your persona already trusts.
- Marketplaces & app directories (e.g. Slack App Directory, Google Workspace Marketplace, Chrome Web Store) if relevant.

## Integration partners (where the agent plugs in)
- The tools your user already lives in — connect there instead of asking them to switch.
- Examples to consider: Slack, Gmail/Google Workspace, Notion, HubSpot/CRM, Linear/Jira, Stripe.
- Each integration = a tool in `agent/tools.py`.

## Platform / infrastructure partners
- Google (ADK + Gemini) — already our stack; lean into the ecosystem story.
- Cloud / hosting for a deployed version.

## Co-sell / channel partners
- Agencies or consultancies who'd resell this to their clients.
