# Submission evidence

The competition rules require screenshots / a PDF for online assets. Capture these
(2 minutes) and drop the images in this folder before the final push:

1. **Landing hero** — `npm run dev` → http://localhost:5173 → full hero with the orb.
2. **Evidence-format showcase** — the "Three layers of evidence" + sample-answer section.
3. **Live agent answer** — start `adk api_server`, ask in the chat
   *"Does this agreement contain a hembudsförbehåll?"* → screenshot the cited, page-referenced answer.
4. **Terminal proof** (optional but strong) — `adk run agent` answering a test case from
   `../../test_prompts.md`, showing the 5-section format with a quoted clause + page.

Name them `01-hero.png`, `02-evidence.png`, `03-live-answer.png`, `04-adk-run.png`.
