How the live demo works

The agent is a standard Google ADK root_agent. Serve it over HTTP and this page streams its answers.

# 1. start the agent API (from repo root)
adk api_server

# 2. open this page — the dot turns green when connected.

If the agent isn't running, the demo falls back to a scripted reply so the page still works.
